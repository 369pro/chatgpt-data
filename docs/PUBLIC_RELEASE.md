# 公开发布说明

此仓库保留当前开发分支的提交历史，并在公开发布前进行了敏感信息清洗。历史提交哈希因此与原始本地仓库不同。

- 私钥、证书文件、本地环境变量文件和运行日志不随代码发布。
- 历史凭据已替换为 `REDACTED`，它不是可用的配置值；部署时请提供自己的凭据。
- 数据库结构与业务参考配置保留，历史用户账户、订单、中奖和流水种子数据已移除。
- 示例中的弱口令仅适用于隔离的本地开发环境，生产环境必须更换，并限制数据库、Redis、管理后台等端口的访问。
- 不要从未清洗的原仓库直接推送分支或标签到此仓库，否则可能重新引入敏感历史。

部署步骤见根目录 README。历史密钥扫描通过不等于生产安全审计；曾经进入 Git 的真实凭据仍应撤销或轮换。
